## 2026-10-18 · Summary
The author's hypothesis: even with standards, everyone models differently; modelling will not standardize.
Both compliance papers support it (madireddy-2025, comcheck-2025: real models are incomplete and inconsistent).

Three ways out:
- Force the standard: Singapore's IFC-SG holds because the permit depends on it.
- Let AI translate the messy model into the standard: partly works, not always right.
- Generate the model, so the standard is a by-product (correct-by-construction).

Between people no standard is needed. It is needed only where a machine reads the model: the code checker,
the quantity take-off, the agent. Free modelling does not need solving; the hand-off does. IFC is exactly
that: an exchange format, not a way of modelling.
