## 2026-11-08 · Summary
Builds a BIM knowledge graph from pure object geometry: machine learning classifies the objects, rules derive hosting and
adjacency, and attributes are computed. Case study: one apartment exported from Revit 2023 as meshes, turned into a
graph, then rebuilt in Revit 2022 from what the graph holds. The classifier used 1,484 object instances from real projects.

Results: a manual comparison of each object pair found that location, dimensions and object types matched. No score and
no tolerance are reported.

For the thesis
- The only Revit to graph to Revit round trip found, and the precedent for the pipeline's first test.
- It drops native data on purpose and infers it again from geometry; the pipeline reads it through the API instead.
- It covers a few classes on one apartment. The pipeline's result on a full sample project, with numbers, goes further.
