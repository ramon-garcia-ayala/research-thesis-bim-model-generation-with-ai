## 2026-10-18 · Summary
Not "automation" but delegation of decisions: each hand gives some decisions to the tool and keeps others.

| Hand | Gives away | Keeps |
|---|---|---|
| Architect / designer | Drawing options, checking code | The criteria: which rules, what weighs more |
| Senior | Reviewing the repetitive | Exceptions, what the rule does not cover |
| Client | — (gains: enters earlier, with data) | Choosing among options with cost and m² |
| Engineers | Preparing inputs | Analysing and signing |
| Contractor | Taking off quantities by hand | Buildability, already at concept stage |

How many passes per hand? More passes, but shorter: the line becomes a loop, and each pass is a review, not a redraw.
Tasks disappear (redrawing, manual checking, transcribing between software); roles made mostly of them shrink.
